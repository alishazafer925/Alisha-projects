# IT Job Market Dashboard
#Project Overview
This project is an interactive power bi dashboard created to analyze the IT job market.
The dashboard helps understand job opportunities, job roles, salaries, location, and other important trends in the IT industry.

# Objectives
-Analyze IT job market data
-Understand different job roles
-Compare salaries
-Identifybjob opportunities by location
-Find important frends and patterns
-present data using interactive visualizations

# Tools & Technologies
-Power BI
-Power Query
-Data Cleaning
-Data Analysis
-Data Visualization

# Project File
The main power BI project file is:
**It Job Market_dashboard.pbix**

# Dashboard Features
The dashboard provides insights into:
- Job Roles
- Salary Analysis
- Job Locations
- Job-related Insights

# Data Preparation
The data was cleaned and transformed using power Query before creating the dashboard.
The data preparation process included:

-Removing unnecessary data
-Handling missing values
-Cleaning and Formatting colums
-Transforming data types
-preparing data for visualization

# Key Insights
The dashboard helps users identify:
-Which IT roles have more opportunities
-Salary differences between job roles
-Locations with more IT jobs
-Overall trends in the IT job market
